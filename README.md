# ことばの森 — 日本語ニュアンスゲーム

5歳から中学生を対象に、場面・同意語・反意語・程度・気持ち・丁寧さなど、日本語の微妙な違いを学ぶブラウザアプリです。

## 起動

`index.html` をブラウザで開くだけで遊べます。外部ライブラリやインターネット接続は不要です。

問題・ヒント・解説には、親しみやすい日本語ニューラル音声（Microsoft Nanami Neural）で事前生成したMP3を使用します。生成音声は聞き取りやすさを保ちながら1.2倍速で再生し、子どもへの自然な話しかけと文ごとの間も原稿段階で調整しています。音声ファイルが利用できない場合だけ、ブラウザの Web Speech API へ自動的に切り替わります。

設定画面の音声選択はフォールバック用です。通常のクイズ音声はブラウザや端末によらず、同梱した音声で同じ品質になります。

## 初期版の内容

- 初級・中級・上級、各10問（全30問）
- 誤答時のヒントと再挑戦
- 正解後のニュアンス比較解説
- 日本語読み上げ、ふりがな、読み上げ速度、動きの軽減設定
- 読み上げは「画面上部の場面説明→同じ場面説明をもう一度→設問を1回→選択肢を1回」の順
- 場面説明、ヒント、正解解説、結果、その他の画面は読み上げない
- 読み上げ中のスピーカーボタンを押すと音声を停止
- 結果、迷った問題だけの復習、端末内の最高記録保存
- 回答した瞬間に音声を停止し、正解・不正解、選んだ答え、正しい答え、詳しい解説を表示
- 回答直後に、正誤、正しい答え、ニュアンス、同意語・反意語、場面差、発展の問いを自然音声で読み上げ
- 画面上部の10問ナビゲーションから、回答済み・未回答の問題へ移動可能
- 未回答中は「この問題を最初から」で、音声とヒントをリセットして同じ問題を冒頭から再開可能
- 10問完了ごとに次の10問を追加でき、各レベル最大100問まで練習可能
- スマートフォン・タブレット・PC対応

## ファイル

- `data/questions.js`: 教材データ
- `js/app.js`: 画面遷移、採点、音声、保存
- `css/styles.css`: レイアウト、キャラクター演出、レスポンシブ表示

個人情報の入力・送信、広告、課金、外部SNS共有、実行時の生成AI接続はありません。
